## 六、复现入口

先按[项目说明](../../../README.md)准备外部 LocalStack 与本机工具。以下脚本只用于本地验证。

1. 用[静态检查工具](复核工具/执行静态检查.ps1)执行 `-Phase initial`。
2. 运行 `e2e/Run-Stage1E2E.ps1 -Suite all -Stage2Session`。全量回归后会输出本轮 `stage2-session.json` 并等待浏览器验收。
3. 按 README 配置 Foundry Local、API 与前端，使用会话里的管理 kubeconfig 和工件桶；页面选择会话中的就绪环境类。
4. 按 TC-01 至 TC-05 操作。用[生命周期证据工具](复核工具/采集生命周期证据.ps1)在各阶段传入 `-SessionFile` 与 `-Phase`；审批前记录必须先于页面批准。
5. Kind 清理前使用[镜像身份工具](复核工具/采集镜像身份.ps1)传入 `-RunDirectory`，需要单独目录时加 `-OutputDirectory`。
6. 完成页面与资源取证后，只删除会话指定的 `stage2-hold.flag`，让原脚本完成其拥有资源的清理；以最终摘要和退出码确认完成。
7. 停止本轮 API、前端进程，用静态检查工具执行 `-Phase final`。

这些复核工具没有引入浏览器测试框架。生命周期采集工具只读查询；[中断恢复清理工具](复核工具/恢复中断后的清理.ps1)会删除对应会话拥有的测试集群、桶与临时目录，正常运行无需使用它。
